VIRALX MVP 1.0

FILES
- index.html: responsive app, interactive personality challenge, results, bilingual ES/EN, sharing, downloadable result card and saved results.
- manifest.webmanifest: PWA metadata and app icons.
- sw.js: basic offline cache for HTTPS hosting.
- icon-192.png and icon-512.png: app icons.

PUBLISH
Upload all five files to the root of a new GitHub repository. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root). Open the published URL on your phone.

CURRENT LIMITS
This is a front-end MVP. Saved results are stored only on the same device/browser. There is no user account, cloud database, real AI service, TikTok API connection, payment processing, public feed, or server-side moderation yet. Do not advertise those as available until implemented and tested.
